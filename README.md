# 数学思维实验室

给准初二学生的互动数学学习网页。核心理念：**先动手，再明白**——不背定义、不刷题海，通过亲手操作发现规律，建立第一性原理式的理解。

**🌐 在线地址（GitHub Pages）：<https://leiyang985-tech.github.io/kutato/>**

## 打开方式

无需安装、无需联网、无需构建——整个应用就是一个 `index.html` 文件：

- **电脑**：双击 `index.html`，用任意现代浏览器打开。
- **手机 / 平板**：把 `index.html` 发送到设备上打开，或访问上面的 GitHub Pages 网址。
- **提示**：`github.io` 在中国大陆的访问可能不稳定。最可靠的方式是直接把 `index.html` 保存到设备本地打开——整个应用就是这一个文件，离线可用，学习进度照常保存。

## 内容

| 模块 | 对应初二知识点 | 互动方式 |
|---|---|---|
| 实验一 · 函数探索器 | 函数概念、一次函数、方程思想 | 破解 5 台"神秘机器"的规则 + 破解后的预测/反向进阶考验；拖动 k、b 滑块观察直线；沿直线拖动"投入→吐出"点；打星挑战 |
| 实验二 · 公式拼图 | 完全平方、平方差、因式分解 | 可拆开的面积拼图；剪开重拼动画；反向积木拼图（因式分解 = 拼图倒着玩）；口算绝活（103×97 秒算） |
| 实验三 · 全等三角形实验室 | SSS / SAS / ASA 判定，SSA 反例，HL 的本质 | 拖动点 C（含实时角度弧线、触屏与键盘支持），亲手找出满足条件的所有位置，自己"证明"判定表 |
| 附录 · 给家长的使用说明 | — | 使用方法、提问话术、三条红线 |

每个模块配有「想一想」思考卡片（先想再点开）和「讲给爸妈听」任务（费曼学习法）。全部实验完成后可领取一张可打印的"毕业证书"。

## 设计要点

- 单文件、零依赖、纯原生 HTML/CSS/JS，不发出任何网络请求。
- 音效由 Web Audio 实时合成（无音频素材）；语音朗读使用系统自带 TTS；两者都有开关（右上角），偏好自动保存。
- 内置"小助手"🦉：进入每页给一句引导；孩子连续猜错、积木超库存等时刻会主动给提示；点它可重听本页引导。
- 自适应手机 / 平板 / 电脑，支持触屏拖拽，自动适配浅色 / 深色主题。
- 学习进度（破解的机器、通过的关卡）保存在浏览器 localStorage 中。
- 视觉语言：方格纸 + 红蓝铅笔批注；数学式采用衬线斜体（教科书排版）。
