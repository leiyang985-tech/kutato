# 一元一次方程 · 互动学习工具

面向初一学生的单页互动学习工具,聚焦初一数学核心知识点 **一元一次方程**。

## 使用方法

直接用浏览器打开 `index.html` 即可,无需安装任何东西,也不需要联网。

## 四个学习环节

1. **认一认** — 概念讲解(「一元」「一次」「方程」三条判断口诀)+ 8 道判断题即时反馈
2. **天平演示** — 把方程当成天平,动手操作理解「等式的性质」;还能故意只动一边,看天平歪掉,体会为什么必须两边同时变形
3. **步步为营** — 4 道典型方程分步选择练习(去分母、去括号、移项、合并同类项、系数化为 1),每个错误选项都对应一个常见失分点并给出针对性讲解
4. **闯关挑战** — 三关难度递进的随机出题(一步方程 → 两步方程 → 两边都有 x),连对 8 题通关;答错立刻展示完整解题过程,历史最佳连对纪录自动保存在本地

## 技术说明

- 纯 HTML/CSS/JavaScript,单文件,零依赖
- 自适应手机 / 平板 / 电脑屏幕
- 跟随系统自动切换浅色(练习本)/ 深色(黑板)主题
